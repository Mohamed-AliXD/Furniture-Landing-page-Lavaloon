# Chapitre Résidentiel Landing Page

A modern, responsive landing page for a luxury residential real estate brand. This project showcases elegant UI design, semantic HTML5 structure, mobile-first responsive development, and accessibility best practices using only HTML and CSS.


## Preview

A clean and modern landing page featuring:

- Hero section with call-to-action
- Residence feature cards
- Customer testimonials
- Call-to-action banner
- Responsive footer with social media links

##  Responsive Design

The layout is designed using a **mobile-first approach** and adapts across different screen sizes.

### Breakpoints

| Screen Size | Layout |
|-------------|--------|
| Mobile | Single-column layout |
| ≥ 400px | Improved footer layout |
| ≥ 768px | Tablet navigation and two-column sections |
| ≥ 1024px | Desktop multi-column layout |
